# Float32 addition before the performance refactor: 2026-09-28

Machine: AMD Ryzen 7 9700X (16 logical processors), Radeon RX 9060 XT, and Radeon integrated GPU
(RADV RAPHAEL_MENDOCINO). Linux 7.0.0-34-generic, GCC 15.2.0, CMake Release build. PACT's CPU
execution currently uses one thread. Both GPUs were discovered and completed their assigned shards.

Each result is the median of 31 timed reads after two warm-ups. Input creation and DAG
construction were excluded. A timed read includes planning, allocation, CPU work, Vulkan setup,
transfers, kernels, synchronization, and output copying. CPU-only used the same binary with Vulkan
loading blocked. `CPU/auto` above 1 means automatic placement was faster. All automatic runs used
two GPU shards, and none fell back to CPU.

The automatic path lost on every measured case. The current planner assigns GPU work using a fixed
size threshold and creates Vulkan devices, pipelines, buffers, and staging for each read. This
implementation is a likely source of the fixed overhead; this benchmark does not time those phases
separately. The 64 MiB temporary budget caps each GPU at 262,144 elements here, so the largest
workload still ran 93.8% of its output elements on the single-threaded CPU path.

Reproduce with the commands in [README.md](README.md). These results describe this machine and
library revision before the refactor, not a general CPU-versus-GPU performance claim. See the
[refactored results](results-2026-09-29-refactor.md) for the new implementation.
